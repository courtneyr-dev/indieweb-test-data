| File | Provenance |
|---|---|
| `fixture-yellow-square.png` | Python standard library and zlib encoded a 48 × 48 RGB PNG. A 24 × 24 yellow square sits on a navy background. |
| `fixture-cyan-stripes.png` | Python standard library and zlib encoded a 48 × 48 RGB PNG with two eight-pixel cyan stripes on the same navy background. |
| `fixture-440hz.mp3` | FFmpeg's sine source generated 1.5 seconds of a mono 440 Hz tone at 22,050 Hz, encoded as 16 kb/s MP3. |
| `fixture-color-bars.mp4` | FFmpeg drew yellow and cyan rectangles over navy and encoded 18 frames at 96 × 64 pixels as H.264. The file has no audio stream. |
| `fixture-color-bars-en.vtt` | The authored WebVTT cue identifies the silent color bars for the full 1.5-second clip. |
| `fixture-orange-inset.png` | Python standard library and zlib encoded a 48 × 48 RGB PNG with a 28 × 18 orange rectangle centered on a navy background. |
